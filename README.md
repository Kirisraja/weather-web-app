# Weather Web App 🌦️

A Java-based Weather Web Application using Servlets and JSP.

## Features
- Search weather by city
- Temperature, humidity, wind speed
- Real-time local clock by timezone
- Weather icons

## Tech Stack
- Java
- Servlet, JSP
- HTML, CSS, JavaScript
- OpenWeather API
- Tomcat

## How to Run
1. Clone this repo
2. Import into Eclipse/IntelliJ
3. Configure Tomcat server
4. Set environment variable:
   OPENWEATHER_KEY=your_api_key
5. Run on server
